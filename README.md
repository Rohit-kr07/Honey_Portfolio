# மதுரை மதுரா — Premium 3D Honey Product Website

React + Vite + Three.js (React Three Fiber) + GSAP ScrollTrigger + Framer Motion.

## Run
```bash
npm install
npm run dev
```

## Assets
All images in `public/assets/` are extracted directly from the original poster
(lion logo, honey jar, 5 honey products, QR code).

## Structure
- `src/components/Hero.jsx` — cinematic landing
- `src/components/Product3D.jsx` — interactive 3D honey jar
- `src/components/Experience.jsx` — honey experience with drip animation
- `src/components/MixedProducts.jsx` — the 5 honey products from the poster
- `src/components/Details.jsx` — info + QR code panel
- `src/components/ContactStrip.jsx` / `Footer.jsx` — poster contact info
